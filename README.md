# AppBuilder

Drag-and-drop Android app builder with Material 3 and Morphicon icons.

## Features

- **Drag-and-drop Designer**: Visual canvas with 25+ built-in components (Button, Text, Image, Input, List, Card, Navigation Bar, Search Bar, Tabs, Toolbar, FAB, Badge, Switch, Checkbox, Radio, Progress, Slider, Divider, WebView, Map, Video, Chart, Grid, Stack, Scroll, Table)
- **465+ Templates**: Complete template library across 21 categories (Social, E-commerce, Tools, Entertainment, Education, Finance, Productivity, Health, Travel, Food, News, Sports, Photography, Music, Video, Weather, Calendar, Chat, Notes, Gallery, AI & Bots)
- **Complete Ready-to-Use Templates**: AI Chat Bot (configure with your API URL/Key/Model), Calculator, Weather, Notes, Music Player, Video Player, Chat, Gallery, Calendar, Todo
- **Code Generation**: Export projects as complete HTML+CSS+JS or full Kotlin Android projects with build.gradle
- **Live Preview**: Real-time preview on phone/tablet frames
- **Morphicon Icons**: 2000+ icons across 30 categories with morphing animation support
- **Material 3 Theme**: Default Material You (dynamic color) theme, with support for importing custom JAR/AAR theme libraries
- **Custom Components**: Create KT, SVG, or Logic components saved permanently in local Room database
- **Project Management**: Auto-save, open, edit, duplicate, delete projects
- **Open Source Fonts**: Configurable open-source fonts
- **GPL-3.0 Licensed**: Free and open source

## Tech Stack

- Kotlin
- Material 3 (Material You)
- Room Database
- Navigation Component
- ViewBinding
- Lottie Animations
- Android-Iconics / Morphicon
- AndroidSVG
- Gson
- Coroutines
